# openchamber

Desktop and web interface for OpenCode AI agent
<br/>
https://openchamber.dev/


```sh
# install
# https://openchamber.dev/download/
# curl -fsSL https://openchamber.dev/install | bash
# bun add -g @openchamber/web
# update
openchamber update
# serve
# OPENCHAMBER_HOST=0.0.0.0
# OPENCHAMBER_UI_PASSWORD=openchamber123
# OPENCHAMBER_PORT=32847
openchamber serve --port 32847 --host 0.0.0.0 --ui-password openchamber123
```
